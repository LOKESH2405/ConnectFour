# ConnectFour
A classic game which is played between two players by dropping the disc into the grid. Whoever places the four discs vertically or horizontally or diagonally will be the winner of the match

# Technologies and algorithms used are
1. Python
2. Pygame
3. Minimax Algorithm
4. numpy and math modules

# How to Play
1. Players take turns dropping discs into the columns.
2. The disc falls to the lowest available row.
3. The first player to connect **four in a row** wins!
4. If the board fills up with no winner, it's a **draw**.
